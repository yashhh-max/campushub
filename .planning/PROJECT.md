# CampusHub Project Definition

## Overview
CampusHub is a full-stack modern college community platform built using Next.js 15 (App Router, Tailwind CSS, TypeScript) and Django 5.1 REST Framework (PostgreSQL, Daphne ASGI, Channels, Redis, SimpleJWT). It centralizes campus events, student organizations (clubs), community communication, digital QR attendance verification, and campus announcements into an integrated collegiate SaaS experience.
