This project operates under strict **Autonomous Full-Stack AI Engineering & Skill Orchestration**.

The full rule charter is permanently codified at:
[.agents/rules/autonomous-skill-orchestration.md](file:///c:/Users/yashw/OneDrive/Desktop/campusHub/.agents/rules/autonomous-skill-orchestration.md)

## Core Directives:
1. **User gives the GOAL**: The agent automatically determines skills, tools, and execution workflow.
2. **Never prompt the user** to choose skills, approve standard tools, or coordinate technical steps.
3. **Multi-Skill Chaining**: Automatically combine design, frontend, backend, security, accessibility, performance, and testing skills.
4. **Visual Tasks Require Visual Verification**: UI/UX work must be visually verified via browser inspection and screenshot tooling before declaring completion.
5. **Preserve Working Architecture**: Use targeted modifications; do not rewrite working systems without cause.
6. **Reporting Standard**: All task completions must strictly follow the Section 24 report format (`Completed`, `Skills / Capabilities Used`, `Files Changed`, `Verification`, `Issues`, `Result`).
